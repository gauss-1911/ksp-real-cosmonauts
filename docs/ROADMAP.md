# Roadmap

1. **Scaffold** - C# plugin project, `GameData/RealCosmonauts` layout, build docs. *(done)*
2. **In-game survey** - developer dump of Kerbal skeletons, meshes, materials and
   animations, including which bones animations move or scale.
3. **Swap prototype** - put a simple placeholder human head on IVA and EVA Kerbals;
   confirm animations and expressions still work; measure how far proportions can change.
4. **Heads** - male and female human heads, several face variants, picked per Kerbal
   from the name so each one always looks the same.
5. **Bodies and suits** - human proportions; realistic IVA and EVA suit textures;
   helmet and visor refitted to the new head. Vintage and future suits after the stock ones.
6. **Coverage and 0.1 release** - crew portraits, Astronaut Complex, main menu;
   compatibility checks; release archive on GitHub Releases.
